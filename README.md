# Zhang Bokai Blog

Astro blog published to GitHub Pages.

## Write a post

Create a Markdown file in `src/content/blog/`:

```md
---
title: "Post title"
description: "Short summary"
pubDate: 2026-06-16
tags: ["tag"]
---

Post body.
```

## Local commands

```bash
npm install
npm run dev
npm run build
```

## Deploy

This repository is configured for GitHub Pages at:

```text
https://zhang-bokai.github.io/blog/
```

In GitHub, open repository settings and set Pages source to **GitHub Actions**.
